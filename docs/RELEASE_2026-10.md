## Порядок

Пути: `SUPA` — `AI-Company-OS\node_modules\@supabase\cli-windows-x64\bin\supabase.exe`,
проект `ivowbhraaistxvoymxpf`. Секреты нигде не печатать и не коммитить.

### 1. Секреты функций и Vault

Сгенерировать три случайные строки (только `A-Za-z0-9_-`, 40 символов): для вебхука, для cron и соль.
Записать во временный файл в scratchpad и поставить одной командой, потом файл удалить:

```
BOOKING_BOT_WEBHOOK_SECRET=<случайная>
BOOKING_CRON_SECRET=<случайная>
BOOKING_IP_SALT=<случайная>
BOOKING_SITE_ORIGINS=https://maestro-booking.vercel.app
BOOKING_SITE_URL=https://maestro-booking.vercel.app
BOOKING_BOT_USERNAME=Maestro_uzbot
MAESTRO_APP_URL=https://maestro-pied-two.vercel.app
```

`SUPA secrets set --project-ref ivowbhraaistxvoymxpf --env-file <файл>`

Тот же `BOOKING_CRON_SECRET` — в Vault (SQL-файлом, не в argv):
`select vault.create_secret('<секрет>', 'booking_cron_secret');`

Проверка: `SUPA secrets list --project-ref ivowbhraaistxvoymxpf` — шесть новых имён;
`select name from vault.secrets` — есть `booking_cron_secret`.

## Откат

- Приложение: `git revert` нужных коммитов и push — Vercel соберёт прежнюю версию.
- Функции: `functions deploy` из коммита `3cd6146`.
- Миграции только добавляют. Снять действие без отката схемы:
  - `select cron.unschedule('maestro-no-mark-fines')` — остановить штрафы в 18:00;
  - то же для `maestro-booking-reminders` и `maestro-booking-holds`;
  - `update settings set auto_fines_since = null` — выключить автоштрафы целиком.
